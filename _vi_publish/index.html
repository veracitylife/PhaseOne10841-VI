PhaseOne10841 — Defensive Agent Security Gateway

Agent EDR for autonomous systems. Watches agents outside the agent— like CrowdStrike for endpoints—not prompt-only hope. Gateway policy, session replay, canaries, A2A firewall, and human approval for destructive actions.

Defensive only. No exploit PoCs, attack payloads, or offensive tooling.

Why Agent EDR

Autonomous agents call tools, talk to other agents, and touch secrets. Prompt-only guardrails are not enough when a swarm can coordinate, escape sandboxes, or tamper with transcripts. PhaseOne10841 puts a control plane in the path of chat completions, tool calls, MCP, and agent-to-agent messages—so policy, detection, and human approval live outside the model.

What it does

  • OpenAI-compatible gateway proxy with YAML policy (domains, shell, filesystem, MCP)
  • Prompt-injection scanning and tool permission analysis
  • A2A firewall with trust levels
  • Harmless canaries, secret egress hardening, and deep redaction
  • MFA admin console, approvals, session replay, SIEM export, metrics, and alerts
  • Detection rules engine, audit log, retention, backups, and local Docker bring-up

Who it is for

  • Security / platform teams — control plane before production tool access
  • AI engineering leads — route LangChain / CrewAI / OpenAI SDK traffic through one gateway
  • SOC / detection engineers — JSONL, webhooks, Prometheus, tunable YAML rules
  • Compliance / risk — audit admin actions, approvals, and session replay
